## 🔑 核心概念（必须掌握）

### 1. 动态功耗公式

```
P_dynamic = α × C × V² × f

α  = 活动因子（0~1，电路翻转比例）
C  = 电容
V  = 电压
f  = 频率
```

**关键洞察**：
- 电压 V 是平方项 → 降电压是降功耗最有效的手段
- 但降电压会降低频率（f ∝ V），所以不能无限降
- 频率提升 20%：如果电压也提 20%，功耗增加 (1.2)²× 1.2 = 1.728 → **73% 功耗增加！**

### 2. Dennard Scaling 及其终结

**Dennard Scaling（1974-2005左右）**：每代工艺缩小，电压和电流同比例下降，频率上升，**功耗密度保持恒定**。

```
每代缩小 s 倍 → V ↓ s, f ↑ s, C ↓ s, P_density ≈ 恒定
```

**2005 年后 Dennard Scaling 失效**：
- 电压不能继续降低（阈值电压卡在亚阈值斜率极限）
- 频率提升停滞在 ~4-5 GHz
- 功耗密度开始上升 → 散热成为瓶颈

### 3. 暗硅问题 (Dark Silicon)

由于功耗限制，芯片上无法同时开启所有晶体管：

```
可用晶体管数 >> 功耗预算可支撑的晶体管数
```

- 典型案例：65nm 工艺下，功耗预算只能支撑 ~50% 区域同时工作
- 28nm 以下更严重
- **设计启示**：与其追求全芯片高速运行，不如用大量专用化、低功耗的 PE

### 4. 能耗效率指标

```
Performance per Watt = Performance / Power
```

- AI 训练场景常用：TFLOPS/W
- WSE-3 能效：~25 TFLOPS / 23 kW ≈ 1.09 GFLOPS/W（需核实最新数据）
- 对比：NVIDIA H100 ≈ 1979 TFLOPS(FP8) / 700W ≈ 2.83 TFLOPS/W

### 5. 晶圆成本与良率模型

**晶圆成本公式**：

```
Cost_per_die = Wafer_cost / (Dies_per_wafer × Yield)

Dies_per_wafer = π × (R²) / Die_area  （近似，R = 晶圆半径）
```

**良率模型（经验公式）**：

```
Yield = (1 - (defects_per_cm² × Die_area) / 2)^2
```

或者更精确的 Bose-Einstein 模型：

```
Yield = exp(-defects_per_cm² × Die_area)
```

**关键参数**：
- 300mm（12英寸）晶圆成本：$3000-$8000
- 缺陷密度：典型 0.1-1.0 defects/cm²（成熟工艺低，新工艺高）

## 🧪 练习题（约 30-60 分钟）

### 基础题

**Q1**：某处理器频率 3 GHz，电压 1.0V，活动因子 α=0.5，电容 C=10nF。计算动态功耗。
> **答**：P = 0.5 × 10nF × (1.0)² × 3GHz = 0.5 × 10×10⁻⁹ × 1 × 3×10⁹ = **15 W**

**Q2**：如果将频率提升 20%（3→3.6 GHz），电压也按比例提升（1.0→1.2V），新功耗是多少？增加了百分之几？
> **答**：
> P_new = 0.5 × 10nF × (1.2)² × 3.6GHz = 0.5 × 10×10⁻⁹ × 1.44 × 3.6×10⁹ = **25.92 W**
> 增加了 (25.92-15)/15 = **72.8%**
> 这就是为什么频率提升越来越贵！

### 进阶题

**Q3**：300mm 晶圆成本 $5000，每个 die 面积 100mm²，缺陷密度 0.3 defects/cm²。用指数良率模型计算：
- 良率 = exp(-0.3 × 1.0) = exp(-0.3) ≈ 76.3%
- 每晶圆 die 数 ≈ π × 150² / 100 ≈ 706 个（理论值，实际有边缘损失，约 ~640）
- 有效 die 数 = 640 × 0.763 ≈ 488
- 单 die 成本 = $5000 / 488 ≈ **$10.25**

**Q4**：Cerebras WSE-3 在整个 46,225 mm² 的晶圆上制造。如果用同样的缺陷密度 0.3 defects/cm² 计算，"晶圆级"良率是多少？
> 注意：WSE 不需要单个 die 良率，而是整个晶圆作为一个芯片！
> Yield = exp(-0.3 × 462.25) = exp(-138.7) ≈ **0**
> 
> 这就是为什么 Cerebras **必须**用 Route-around 技术——不能指望整个晶圆零缺陷！
> 实际策略：制造时容忍缺陷，将坏掉的 PE 在软件层面（CSL）屏蔽。
> Cerebras 通过冗余设计：每个晶圆额外保留 ~1.5% 的备用核心来替换缺陷核心。

### 思考题（与 WSE 研究关联）

**Q5**：假设标准 GPU die 面积 800mm²，缺陷密度 0.5 defects/cm²。比较：
- (a) 1 个大 die (800mm²) 的良率
- (b) 4 个小 die (200mm² 各) 的良率
- (c) 4 个小 die 全部可用的概率

> (a) Yield = exp(-0.5 × 8) = exp(-4) = 1.8%（极低！）
> (b) 单个小 die Yield = exp(-0.5 × 2) = exp(-1) = 36.8%
> (c) 四个全部合格 = 0.368⁴ = 1.8%（巧合地相同！但关键区别在于：小 die 方案可以"挑好的"——只有 1 个坏了还能用 3 个；大 die 一坏就全废）
> 
> **核心洞察**：这就是 Chiplet 方案的经济优势——**缺陷导致的损失被隔离到了单个小 die**。Cerebras 选择了一条完全不同的路：用软件容错代替硬件良率。

## 🔗 与 WSE / NoC 研究的关联

### 今日概念 → 研究方向映射

| 概念 | WSE 研究 | NoC 研究 |
|------|----------|----------|
| 动态功耗 P=αCV²f | WSE PE 极简化 → 降 α、C → 低功耗 per PE | NoC router 功耗也是 αCV²f |
| Dennard Scaling 终结 | 解释了为什么不能靠提频提升性能 → 靠并行 | NoC 也是多核时代的产物 |
| 暗硅问题 | WSE 的 PE 设计理念：宁可极简也不暗硅 | 路由器的功耗预算优化 |
| 良率模型 | **WSE 最大的挑战！** Route-around 是直接对策 | 不直接相关，但 chiplet 互连可靠性有关 |
| 成本模型 | WSE 商业可行性的核心问题 | 不直接相关 |

### 深度思考：WSE 良率策略的代价

Cerebras 选择 **"接受缺陷 + 软件容错"** 而不是 **"追求完美 + 硬件冗余"**：
- ✅ 不需要丢弃有少量缺陷的晶圆
- ✅ 随着工艺成熟，有效 PE 数量增加（免费性能提升）
- ❌ 编程模型变复杂（CSL 需要处理 PE 映射）
- ❌ 性能有不确定性（不同晶圆可用 PE 数不同）
- ❌ 测试和标记缺陷 PE 需要额外流程

**开放问题**：如果缺陷密度降到 0.01/cm²（未来工艺成熟），WSE 的优势是否会缩小？
