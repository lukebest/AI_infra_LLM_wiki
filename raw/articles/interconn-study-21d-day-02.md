## 🔑 核心概念（必须掌握）

### 1. 电路交换 vs 报文交换 vs 分组交换

```
源 ──────→ 节点1 ──────→ 节点2 ──────→ 目的
            [中转/存储]
```

| 交换方式 | 关键特征 | 优势 | 劣势 |
|----------|----------|------|------|
| **电路交换 (Circuit)** | 通信前先建立**专用通路**，传输期间独占 | 传输时无争用、延迟确定 | 建路开销大、资源利用率低 |
| **报文交换 (Message)** | 整报文**存储转发**到下一节点 | 简单、容错好 | 大报文阻塞整条链路、延迟大 |
| **分组交换 (Packet)** | 报文拆成**固定大小包**，逐包存储转发 | 平衡延迟与利用率 | 需要重组、有乱序问题 |
| **虫孔交换 (Wormhole)** | 包拆成 flit，head flit 选路，后续 flit 流水 | 极低延迟、缓冲小 | 头阻塞会锁住整条物理通道 |

**关键洞察**：从电路→报文→分组→虫孔，本质是在做**用更多状态换更短延迟**的权衡。
- 电路：状态在端（通路），中间无状态
- 报文：状态在每个中间节点（缓冲）
- 虫孔：状态只在 head flit 路径上，body 跟随

### 2. 互连网络的时代划分

```
电话网 (1900s)     → 电路交换、时分复用
        ↓
ARPANET/Internet (1970s) → 分组交换、IP
        ↓
HPC/MIN (1980s)   → 多级互连、Hypercube、Mesh
        ↓
SAN/LAN (1990s)   → Fibre Channel、Ethernet
        ↓
SoC/NoC (2000s)    → 片上 Mesh、Tile-based、WSE
        ↓
现代 (2020s)       → Silicon Photonics、Wafer-Scale、CXL
```

**关键洞察**：每个时代都对应**一种新的物理介质**和**一种新的优化目标**——
- 电话网：物理介质 = 铜线；目标 = 通话质量
- HPC：物理介质 = 专用链路；目标 = FLOPS/$ 
- NoC：物理介质 = 硅互连；目标 = 功耗/面积
- Wafer-Scale：物理介质 = 单晶圆；目标 = 延迟/聚合带宽

### 3. 重要里程碑

| 年份 | 里程碑 | 意义 |
|------|--------|------|
| 1960s | Clos Network | 提出严格无阻塞三级交换结构 |
| 1970s | Store-and-Forward MIN | 报文交换用于并行机 |
| 1985 | Dally 的 Torus 论文 | 系统化分析 k-ary n-cube |
| 1987 | **Wormhole Routing** (Dally & Seitz) | 极低延迟的虫孔交换 |
| 2001 | "Route Packets, Not Wires" (Dally) | **NoC 概念正式提出** |
| 2007 | Intel Polaris / TeraFLOPS | 80 核 5GHz Mesh 实验芯片 |
| 2019+ | Cerebras WSE-2/WSE-3 | 90 万 PE 单晶圆 NoC |

### 4. 接口层次：物理层 → 链路层 → 网络层 → 传输层

```
┌────────────────────────────────────┐
│ 传输层 (Transport)                 │  ← 端到端、可靠/有序、流控
├────────────────────────────────────┤
│ 网络层 (Network)                   │  ← 路由、包格式、拥塞信号
├────────────────────────────────────┤
│ 数据链路层 (Link)                  │  ← 错误检测、重传、链路训练
├────────────────────────────────────┤
│ 物理层 (Physical)                  │  ← 编码、SerDes、信道
└────────────────────────────────────┘
```

**类比 Internet**：NoC 的这 4 层和 TCP/IP 协议栈**几乎一一对应**——
- 物理层：片上 wire / 收发器
- 链路层：流控（credit-based、ACK/NACK）
- 网络层：路由（XY、自适应）
- 传输层：拥塞控制、可靠传输

### 5. 简单接口示意

```
┌──────────┐   物理层   ┌──────────┐
│  Router  │←─wire/flit─→│  Router  │
└──────────┘             └──────────┘
     ↑                         ↑
   网络接口                   网络接口
   (NI - Network Interface)
     ↑
   CPU/PE 核心
```

**关键洞察**：NI (Network Interface) 是**网络和计算的边界**——决定了"哪些操作可以卸载到网络"、"哪些必须软件完成"。

## 🧪 练习题（约 30-60 分钟）

### 基础题
**Q1**：画出互连网络的 4 层设计空间层次图（应用/算法 → 拓扑/路由/流控 → 微架构），并标注每层的核心问题。

**Q2**：用对比表列出**电路交换**和**报文交换**的优缺点，至少从 5 个维度对比：
- (a) 建路开销
- (b) 资源利用率
- (c) 延迟确定性
- (d) 容错性
- (e) 适合的流量特征

**Q3**：用自己的话解释**为什么虫孔交换**比报文交换延迟低？它带来了什么新问题？

> 答：虫孔交换把包拆成 flit，head flit 一边选路一边前进，body 跟着走。报文交换必须整包到达下一节点再转发，所以延迟 ≈ 跳数 × 整包传输时间。虫孔 ≈ 跳数 × 单 flit 传输时间 + 流水线填充。
> 新问题：头阻塞（head-of-line blocking）—— 一个 head 卡住会锁住整条物理通道。

### 进阶题（与研究关联）
**Q4**：Cerebras WSE 的互连选择了**虫孔交换**（wormhole routing 的变体）。为什么虫孔比电路交换更适合 WSE 的流量特征？

> 答：WSE 的流量是 LLM 推理的**突发性短消息**（activation、gradient）。如果用电路交换：
> - 每次通信都要建路/拆路，**开销远大于数据本身**
> - 46,000+ 节点建路调度复杂度爆炸
> 
> 用虫孔：单 flit 即可注入，开销极小；与 LLM 的 all-reduce 等 collective 操作天然契合。
> **本质**：流量越短、越随机，越适合分组/虫孔；流量越长、越稳定，越适合电路。

**Q5**：WSE-3 单芯片约 90 万 PE，分布在 ~750×750 的 Mesh 上。如果用电路交换建一条穿越 750 跳的通路，需要占用多少物理链路？这对 WSE 的设计意味着什么？

> 答：电路交换下，**整条通路上的 750 条物理链路都会被独占**。
> 后果：
> - 流量并发度急剧下降
> - 与 LLM 推理的高并发流量特征严重不匹配
> - 这就是为什么 WSE 必须选虫孔/分组交换
