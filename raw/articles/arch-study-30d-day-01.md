## 🔑 核心概念（必须掌握）

### 1. CPU 性能公式（最重要！）

```
CPU Time = Instruction Count × CPI × Clock Cycle Time
         = (IC × CPI) / Clock Rate
```

**三个因子各自由什么决定？**
- **IC (Instruction Count)**：由 ISA、编译器、算法决定
- **CPI (Cycles Per Instruction)**：由微架构决定
- **Clock Rate**：由工艺、功耗、设计复杂度决定

**关键洞察**：三个因子不是独立的！例如：
- 提高 Clock Rate 可能增加 CPI（因为流水线级数增加 → 分支惩罚增大）
- 减少 IC（用复杂指令）可能增加 CPI（复杂指令需要更多周期）
- 这就是体系结构的**核心权衡**

### 2. Amdahl 定律

```
Speedup = 1 / ((1 - f) + f / S)

f = 可加速部分占比
S = 加速部分的加速比
```

**推论**：即使某部分加速无限大，总体加速比上限 = 1/(1-f)
- 50% 可加速 → 最大 2×
- 90% 可加速 → 最大 10×
- 99% 可加速 → 最大 100×

**关键启示**：找到瓶颈（最慢的部分），集中精力优化它。

### 3. 局部性原理

- **时间局部性**：最近访问的数据可能再次被访问
- **空间局部性**：地址相近的数据可能被一起访问
- **这是所有存储层次设计的理论基础**

## 🧪 练习题（约 30-60 分钟）

### 基础题
**Q1**：某程序中，浮点运算占执行时间的 40%。如果浮点单元速度提升 5×，总体加速比是多少？
> 答：f=0.4, S=5 → Speedup = 1/(0.6+0.4/5) = 1/0.68 ≈ 1.47×

**Q2**：CPU A 运行某程序需要 10 秒，CPI=3.0，时钟频率 2GHz。CPU B 有相同 ISA 但 CPI=2.0，时钟频率 3GHz。在 B 上运行同一程序需要多少秒？
> 答：IC = 10s × 2GHz / 3.0 = 6.67×10⁹ 条指令
> B 上时间 = 6.67×10⁹ × 2.0 / 3GHz = 4.44 秒

### 进阶题
**Q3**：某处理器有三种指令：ALU (CPI=1, 50%), Load/Store (CPI=3, 30%), Branch (CPI=2, 20%)。
- 平均 CPI = 0.5×1 + 0.3×3 + 0.2×2 = 1.8
- 如果通过优化将 Load/Store 的 CPI 降到 2，新的 CPI 和加速比是多少？

### 思考题（与 WSE 研究关联）
**Q4**：Cerebras WSE-3 有 900,000 个 PE，每个 PE 极简（无乱序、无分支预测、无 Cache）。如果将一个有 50% 可并行的工作负载放在 WSE 上运行，理论上最大加速比是多少？实际可能受到什么限制？
