## 摘录数字（仅幻灯片正文）

- HBM takes **3×** the die area of DDR。
- DRAM wafer volume **static for >10 years**；新产能 **>2 years** 才能装上。
- spot 图：branded DRAM **7.1×**、NAND **6.9×**（相对低点倍数；绝对 $/GB 未知）。
- 超大规模资本开支与内存营收绝对 $B 刻度 **未知**。
- 预告 Objective Analysis HBM 报告，**September** 可从 Objective-Analysis.com/reports 下载。

## 要点

- 短缺三驱动：AI 开支超预期；带宽吃掉过量晶圆；产能十年未涨。
- 增长主要来自涨价。
- 长期：推理从 MCU 到 hyperscale LLM；PIM 三条（HBM base die / 定制 memory / 低端 Analog Neural Nets）；软件支持弱是 gating factor。
- 信道带宽需求与两端智能成反比。
